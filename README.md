# Pellizzaro

**Computer Engineer | Hardware Performance & Systems Optimization | Brazil**

I am focused on understanding why hardware performs the way it does — and how to make it faster, more efficient, and more reliable.

My interests are centered on **GPU voltage–frequency tuning, CPU and memory optimization, performance validation, and low-level systems behavior**. I plan to begin studying Computer Engineering in 2027, with the long-term goal of working on GPU performance characterization and determining stable, efficient operating limits for real hardware.

I care about measurable improvement: identifying bottlenecks, testing changes, and finding the best balance between performance, power, latency, temperature, and stability.

## Technical interests

- **GPU performance:** voltage–frequency curves, overclocking, undervolting, memory tuning, performance-per-watt, and stability validation.
- **CPU and memory:** BIOS/UEFI configuration, DRAM timings, clock and voltage behavior, and system-level bottlenecks.
- **Software and systems:** Windows and Linux performance, graphics workloads, shader compilation, frame pacing, and input latency.
- **Engineering methodology:** controlled comparisons, benchmarking, repeatability, and trade-off analysis.

My hands-on experience includes tuning an **AMD Ryzen 7 5700X**, **AMD RX 7600** and an **NVIDIA GeForce RTX 5060**, testing operating points and optimizing a constrained consumer platform. I am especially interested in the validation work behind choosing safe GPU clocks and voltages at scale.
